# Pedro Candeias · GitHub Pages

A página raiz encaminha para [a homepage do projeto de mestrado](https://pedrocandeias.github.io/IPCA-MDDP-2026-PEC/index.html).

O GitHub Pages publica a raiz da branch `main`. O ficheiro `index.html` usa `location.replace` e inclui `meta refresh` e uma ligação direta como alternativas sem JavaScript. O ficheiro `.nojekyll` mantém a publicação estática.

A fonte e as notas de manutenção também estão no [repositório do projeto](https://github.com/pedrocandeias/IPCA-MDDP-2026-PEC/tree/main/docs/capitulos/html/manuscrito_citacoes/publicacao/redirecionamento_raiz).
